# Discount Calculator System

## Introduction
This project is about a Discount Calculator System. It is designed to help users calculate the total price of packages and find the discount they receive when buying multiple packages.

## How the System Works
The user enters the number of packages and the price of each package. The system calculates the total price and applies a discount depending on the number of packages purchased.

Customers who buy more packages receive a higher discount. This helps customers save money when purchasing in large quantities.

## Discount Information
- Buying 10 or more packages gives a 20% discount.
- Buying 20 or more packages gives a 30% discount.
- Buying 50 or more packages gives a 40% discount.
- Buying 100 or more packages gives a 50% discount.
- Buying fewer than 10 packages gives no discount.

## Main Features
- Easy to use.
- Calculates package prices automatically.
- Provides discounts based on quantity.
- Displays the final price.
- Shows error messages when incorrect information is entered.
- Allows users to clear information and start again.
- Allows users to close the application.

## Conclusion
This project makes price calculations easier and faster. It helps users understand discounts and the final amount they need to pay. It is a simple and useful application for learning how a discount calculator works.
