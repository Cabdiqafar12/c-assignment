# c#assignment

C# Windows Forms Assignments

This repository contains my C# Windows Forms assignments developed using Visual Studio.

Assignments

# Assignment 1 – Full Date

This program collects the following information from the user:

* Day of the week
* Day of the month
* Month number
* Year

The program combines the entered information and displays the complete date when the Show button is clicked.

It also includes a Clear button that removes all entered data and clears the output.

# Assignment 2 – Student Information

This program collects student information:

* Student Name
* Student ID
* Department
* Semester

When the Show button is clicked, the program displays the student’s information in the output label.

The program also includes:

* Clear button – clears all input fields and output.
* Exit button – closes the application.

Technologies Used

* C#

* Visual Studio
* .NET

Features
