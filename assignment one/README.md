Description

This project is a simple C# Windows Forms application that allows users to enter and display date information. Users can enter the day of the week, day, month, and year. The application includes Show and Clear buttons.

Features

- Enter date information
- Display full date
- Clear input fields
- Simple Windows Forms interface

Technologies Used

- C#
- Windows Forms
- Visual Studio

How It Works

1. Enter the day of the week.
2. Enter the day, month, and year.
3. Click the Show button to display the full date.
4. Click the Clear button to remove all input.

Example Output
