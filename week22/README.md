### 1. Submit

When the user enters the **Student Name, Student ID, Department,** and **Semester**, and then clicks the **Submit** button, the program reads the entered information. The data is stored in **variables** and then displayed in the **Output** section.

![alt text](<screenshot/creating variables.jpg>)

### 2. Clear

The **Clear** button is used to remove all the information entered in the input fields. It also clears the **Output** section, allowing the user to enter new information.

![alt text](<screenshot/clear textbox.jpg>)

### 3. Exit

The **Exit** button is used to close the program. When the user clicks **Exit**, the Windows Form closes and the program is terminated.

![alt text](<screenshot/EXIT .jpg>)
