### Objects

An object is an instance of a class that represents something in a program.

Examples: Car, Student, Button.

Dim student As New Student()

### Controls

Controls are elements used to interact with the user in a Windows Form.

Examples: TextBox, Button, Label, CheckBox.


### The Toolbox

The Toolbox contains controls that you can add to a Windows Form.

Examples: Button, TextBox, Label, CheckBox.


### Displaying the Designer

The Designer is used to create and design the Windows Form visually.

Example: Adding a Button or TextBox to the form.

### The Form’s Bounding Box and Sizing Handles

The bounding box shows the edges of the form, while sizing handles are used to resize it.

Example: Drag a corner handle to make the form bigger or smaller.


### The Properties Window

The Properties Window is used to view and change the properties of a control.

Examples:

Text → Changes the text displayed.
Name → Changes the control name.
BackColor → Changes the background color.
Font → Changes the font style.


### Adding and Deleting Controls

Adding Controls: Drag a control from the Toolbox to the form.

Deleting Controls: Select the control and press Delete.

Example: Add a Button → Select it → Press Delete to remove it.

### Introduction to C# Code

C# is a programming language used to create applications.

Example:

int age = 20;

### Message Boxes

A Message Box displays a message or information to the user.

Example:

MessageBox.Show("Hello World!");

### Label Controls

A Label displays text or information on a form.

Example:

label1.Text = "Student Name";


### Organization of the Form1.cs

Form1.cs contains the C# code for the Windows Form.

Examples: Variables, methods, button events, and other program logic.
